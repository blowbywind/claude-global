다음 작업에 대해 코드를 작성하기 **전에** 반드시 아래 형식으로 계획을 먼저 제시하세요:

## 작업 계획

### 1. 목표

- 무엇을 달성하려는가?

### 2. 영향 범위

- 수정될 파일 목록
- 영향받는 모듈/기능

### 3. 단계별 작업

1. [ ] Step 1
2. [ ] Step 2
3. [ ] Step 3

### 4. 리스크 & 대응

- 예상 리스크
- 롤백 방법

### 5. 검증 방법

- 어떻게 성공을 확인할 것인가?

**작업 요청**: $ARGUMENTS

계획 승인 전까지 코드 작성을 시작하지 마세요.

---

## 승인 후 실행 절차

사용자가 계획을 승인하면 즉시 TodoWrite 툴로 단계별 항목을 생성하세요:

```
각 "단계별 작업" 항목 → TodoWrite pending 항목으로 등록
작업 시작 시 → in_progress로 변경
완료 즉시 → completed로 표시 (배치 처리 금지)
```

이렇게 하면 세션 압축 후에도 남은 작업이 보존되고, 범위 이탈을 방지합니다.
