## 오늘 배운 것
- Anthropic 현행 라인업(Sonnet 5·Fable 5·Mythos 5·Opus 5)은 기존 위키 검증(2026-08-08, platform.claude.com 1차 문서 직접대조) 결과와 일치 — 재확인됨. 단, 오늘 리서치가 인용한 출처(releasebot.io)는 1차 소스가 아니므로 이 사실은 **기존 검증에 근거해 유지**하는 것이며 오늘 자료로 신규 검증된 것은 아닙니다.
- 이번 리서치의 나머지 주요 주장(Claude Code 기능 추가, 생물안전 85% 감소 수치, Codex GPT-5.4 은퇴일, GPT-5.6 Sol/Terra/Luna 원문대조, 업계 가격전쟁 수치, Gemini 3.7 Flash·Muse Code)은 전부 폐기합니다 — 근거:
  - `releasebot.io`, `aitoolsrecap.com`, `gradually.ai`는 Anthropic/OpenAI/Google 공식 도메인이 아닌 비1차 아그리게이터로, 기존 위키 "리서치 환각 패턴 목록"(2026-07-05) 폐기 기준("비공식 서브도메인 출처는 리서처 직접 확인 없이 채택 금지")에 정확히 해당합니다.
  - GPT-5.6 Sol/Terra/Luna "원문대조 완료"로 표기된 `learn.chatgpt.com`, `deploymentsafety.openai.com`도 OpenAI의 알려진 공식 도메인 패턴(openai.com/platform.openai.com/help.openai.com)과 불일치해 도메인 자체가 의심스럽습니다. 기존 위키 초안(2026-08-18)엔 "Terra만 조작"으로 남아 있어 오늘 주장과 상충 — 어느 쪽도 신뢰도 낮아 **둘 다 미채택**.
  - Antigravity Gemini 항목은 리안 스스로 "429 오류로 원문 재대조 실패"라 명시했으므로 자동 폐기.
