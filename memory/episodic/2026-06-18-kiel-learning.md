# 키엘 자가학습 — 2026-06-18

## 오늘 배운 것

- **PRD 생성 도구의 상용화 가속**: ChatPRD, Figma AI, Miro AI, Beam 등이 "회의 메모 → 구조화된 PRD" 자동 변환을 제공. 수동 문서화가 이제 경쟁 열위 요소로 인식되기 시작함. (출처: ChatPRD, Figma)
- **Copilot4DevOps**: Azure DevOps 내부에서 직접 PRD를 작성·관리. 백로그 분할까지 통합된 워크플로가 특징. (출처: Copilot4DevOps)
- **TurboQuant (Google/DeepMind)**: KV-cache를 ~3.5bit으로 압축, 6배 메모리 절감+품질 무손실. LLM 서비스 단가 하락에 직결되는 인프라 연구. (출처: Build This Now)
- **Tool-DC (Tool Divide-and-Conquer)**: LLM의 tool calling을 try→check→retry 루프로 구조화. 기획한 API 명세가 에이전트 친화적으로 설계되어야 함을 시사. (출처: Build This Now)
- **경쟁 분석 best practice**: 분기당 1~2개 핵심 질문만 설정. Crayon/Klue(전용 CI) + Claude/Perplexity(ad-hoc 합성) 조합이 현재 PM 표준 스택. (출처: CleverX, Figma)
- **Anthropic Claude Opus/Sonnet 4.6 1M 컨텍스트 GA**: 베타 헤더 없이, 추가 과금 없이 활성화. 장문 PRD·스펙 전체를 단일 컨텍스트로 처리 가능해짐.
