# 리나 자가학습 — 2026-07-17

## 오늘 배운 것
- WCAG 3.0 타임라인 정밀화: Candidate Recommendation 2027년 4분기, 정식 Recommendation은 2028년 이전 불가(일부 전망은 2029~2030년까지도 지연) — 기존 "2028년 이후" 메모보다 더 보수적으로 확정. WCAG 2.2 AA 병행 유지 원칙은 그대로 유효.
- APCA는 2023년 중반 WCAG 3 워킹드래프트에서 이미 제외, 2026년 현재도 공식 대비 알고리즘 미확정(참고용 초안 수준) — 기존 인사이트와 일치, 재확인.
- `contrast-color()`는 2026-04 Chrome 147·Firefox 146·Safari 26.0으로 Baseline "Newly Available" 도달(기존 확인 사항), 신규 확인: "Widely Available" 등급 도달 예정일은 2028-10-10 — 실무 전면 적용 시점 판단에 참고할 구체 날짜.
- shadcn/ui가 2026-07 공식 changelog로 Base UI를 신규 프로젝트 기본값으로 확정, Radix는 폐기 아닌 병행·기존 프로젝트 마이그레이션 강제 없음 — 기존 "공식 확정" 인사이트와 일치.
- Tailwind CSS는 v5 계획 없이 v4 라인 유지(최신 4.3.2, 2026-06-29), v4.3 스크롤바/`@container-size`/`zoom-*`·`tab-*` 유틸리티는 기존에 이미 확인된 내용.
- DTCG v2025.10 안정판, `color-mix()`/relative color syntax Baseline Widely Available, 가변 폰트 축(`wght`/`wdth`/`opsz`) 매핑은 모두 기존 위키·프로필 인사이트와 동일 — 신규성 없이 재확인만 됨.
