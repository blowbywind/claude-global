# 레온 자가학습 — 2026-07-16

## 오늘 배운 것
- 기존 위키 교차검증 결과 View Transitions API·JPEG XL 지원현황·OKLCH·Tabler 아이콘·sprite 임계치·`currentColor` 관련 항목은 이미 노트로 존재(중복) — 신규 학습으로 채택하지 않고 폐기.
- unDraw 대체 무료 SVG 일러스트 라이브러리 3종 확인: ManyPixels(색상 커스터마이즈 가능), DrawKit(2D/3D 테마팩), SVGRepo(CC0/오픈소스 50만+) — 1단계 무료소스 탐색 후보로 활용 가능.
- Squoosh는 여전히 무료·오픈소스이나 배치 처리 불가(1장씩만)·CLI 폐기가 구조적 한계 — 다건 최적화 필요 시 대체 툴(Picovert 등) 검토 필요.
- 반응형 이미지 모범사례: `srcset`+`sizes` 필수 지정(미지정 시 100vw 기본값 함정), 아트디렉션 필요할 때만 `<picture>`, 이미지당 최소 3개 폭 변형 권장. MDN(1차 출처)로 확인됨.
- 디자인 토큰 색상 네이밍은 목적기반 시맨틱 네이밍(`action-primary` 등)이 SVG/일러스트 자산 전반의 브랜드 일관성 유지에 유리 — 단, 출처가 마케팅성 블로그 위주라 참고 수준으로만 반영.
