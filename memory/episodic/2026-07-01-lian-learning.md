## 오늘 배운 것

- **ALE 성능 절벽 패턴 심화** — 기존 추적 중인 ALE 벤치마크에서, 최고 난이도 전문직 장기 태스크 구간은 최신 프론티어 에이전트들도 성공률 0% 수렴이 확인되고 있음. "벤치마크 포화(saturation)" 문제가 아니라 **에이전트 능력의 실질 상한선**을 측정하는 지표로 활용 가능.
- **LongMemEval-V2 5축 구조** — 정적 상태 회상 / 동적 상태 추적 / 워크플로 지식 / 환경 장애물(gotchas) / 전제조건 인지. 수치(72.5% 등)는 출처 미특정으로 채택 보류, 구조 분류만 참고.
- **Anthropic 모델 교체 주기 가속 재확인** — Sonnet 4·Opus 4 은퇴(메모리 기존 기록)가 리서치에서도 재등장. 봇 스폰 프롬프트의 모델명은 지속 점검 필요.
- **리서치 폐기 필터 실전 적용 사례** — "GPT-5.5", "Composer 2.5", "Opus 4.8" 모두 이번 라운드에서 필터로 제거됨. **소수점 버전·미확인 모델명·generic URL 조합**은 환각 밀도가 높음.
