## 오늘 배운 것

- **Next.js 16.2.7 출시 (현재 안정 버전)**: Turbopack이 dev/build 기본 번들러로 전환, Cache Components 베타 도입, Node.js 최소 요구사항 20으로 상향. — [출처](https://www.abhs.in/blog/nextjs-current-version-march-2026-stable-release-whats-new)

- **Drizzle ORM이 Prisma를 대체하는 추세**: TypeScript 통합 우수성·경량·SQL-first 설계로 AI 에이전트들이 기본 ORM으로 추천 전환 중. Prisma는 여전히 사용되지만 신규 스택 추천에서 밀림. — [출처](https://encore.dev/articles/typescript-backend-stack-2026-ai-agents)

- **Hono가 Fastify를 위협**: 벤치마크에서 Express 대비 2-4배, Fastify와 동등 이상의 처리량. 엣지/서버리스 환경에서 특히 강세. Bun + Hono + Drizzle 조합이 2026 고성능 스택으로 부상. — [출처](https://quartzdevs.com/resources/best-backend-frameworks-2026-top-server-side-tools)

- **AI 코딩 도구 시장 구도 재편**: JetBrains 2026 조사 기준 Copilot 29% / Cursor 18% / Claude Code 18%. 10년+ 시니어 개발자 중 46%가 일상 도구로 Claude Code 선택. GitHub Copilot은 2026년 6월부터 $10 플랜을 월 1,500 크레딧 제한으로 변경. — [출처](https://lushbinary.com/blog/ai-coding-agents-comparison-cursor-windsurf-claude-copilot-kiro-2026/)

- **Cursor ARR 급성장**: 2025년 1월 $100M → 2025년 11월 $1B → 2026년 2월 $2B. 속도 기준 가장 빠른 SaaS 성장 사례 중 하나. — [출처](https://www.programming-helper.com/tech/ai-coding-agents-2026-cursor-claude-copilot-enterprise-comparison)
